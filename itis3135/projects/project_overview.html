Project Overview

Application Description & Purpose

This website is dedicated to Sharon Walker's small business, Luxury Browns Sweets & Treats, which specializes in a delicious variety homemade baked goods such as cakes, cobblers, cookies, and cupcakes. It will feature a menu, gallery, events schedule, and more.

The purpose of this website is to promote the business, and showcase products and upcoming events so that customers can stay in the know and make inquieries at ease. There will be a large emphasis in user accesibility in order to strengthen engagement.

Intended Audience

  • Customers interested in purchasing baked goods
  • Event attendees
  • Community members supporting local businesses

Overview of Website Content

  • Business introduction, location, and mission statement
  • Product menu
  • Gallery
  • Events schedule
  • Contact information and inquiry form

Page Design

Home

  • Purpose: Introduce the business
  • Audience: All users
  • Content: Business name, featured items, description
  • User Input: No
  • Elements: Images, sections, buttons, navigation
  • Actions: Navigate to other pages

Menu

  • Purpose: Display products
  • Audience: Customers
  • Content: Cakes, cookies, cobblers, cupcakes
  • User Input: No
  • Elements: Categories, images
  • Actions: Optional filtering using JavaScript

Gallery

  • Purpose: Showcase images
  • Audience: Customers
  • Content: Photos of baked goods
  • User Input: No
  • Elements: Image grid
  • Actions: Click to enlarge images

Events

  • Purpose: Display upcoming events
  • Audience: Customers
  • Content: Event name, date, location
  • User Input: No
  • Elements: Event list
  • Actions: View event details

Contact

  • Purpose: Allows order requests
  • Audience: Customers
  • Content: Contact info and form
  • User Input: Yes
  • Fields: Name, Email, Message, checkbox for specifying whether order is catering/special event
  • Validation: Required fields
  • Actions: Form validation using JavaScript

JavaScript Dynamic Functionality

Features:

  • The contact page will have form validation for inquiries & engagement
  • Image gallery interaction so that users may click on images to enlarge for enhanced visibility
  • Menu filtering by category through sections
  • Navigation highlighting for aesthetics
