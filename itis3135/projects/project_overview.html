Luxury Browns Sweets & Treats

Application Description & Purpose

This website is dedicated to Sharon White, a small business owner in North Carolina of a bakery named Luxury Browns Sweets & Treats. The shop specializes in a delicious variety of homemade baked goods such as cakes, cobblers, cookies, and cupcakes. As per my client's request, the website will feature a menu, gallery, events schedule, and more.

This project's purpose is to promote the business and showcase products and upcoming events so that customers can stay in the know while making inquieries at ease. There will be a large emphasis in user accesibility in order to strengthen engagement.

Intended Audience

  • Customers interested in purchasing baked goods
  • Event attendees
  • Community members supporting local businesses

Overview of Website Content

  • Business introduction, location, and mission statement
  • Product menu
  • Gallery
  • Events schedule
  • Contact information and inquiry form

Home

  • Purpose: Introduce the business & location(s)
  • Audience: All users
  • Content: Business name, featured items, navigation to other pages, and a login feature
  • User Input: Login
  • Elements: Images, sections, buttons, navigation
  • Actions: Navigate to other pages

Menu

  • Purpose: Display products
  • Audience: Customers
  • Content: Cakes, cookies, cobblers, cupcakes
  • User Input: No
  • Elements: Categories, images
  • Actions: Optional filtering using JavaScript

Gallery

  • Purpose: Showcase products by type
  • Audience: Customers
  • Content: Photos, descriptions, and titles of baked goods
  • User Input: No
  • Elements: Images
  • Actions: Click to enlarge images

Events

  • Purpose: Display upcoming events
  • Audience: Customers
  • Content: Event name, date, location
  • User Input: No
  • Elements: Event list
  • Actions: View event details

Contact

  • Purpose: Allows order requests
  • Audience: Customers
  • Content: Contact info and form
  • User Input: Yes
  • Fields: Name, Email, Message, checkbox for specifying whether order is catering/special event
  • Validation: Required fields
  • Actions: Form validation using JavaScript

JavaScript Dynamic Functionality:

  • The contact page will have form validation for inquiries & engagement
  • Image gallery interaction so that users may click on images to enlarge for enhanced visibility
  • Menu filtering by category through sections
  • Navigation highlighting for aesthetics
